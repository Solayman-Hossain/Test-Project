# Test-Project

A Node.js web app built with **TypeScript** and **Next.js** (App Router).

## Tech stack

| Layer | Choice |
| --- | --- |
| Runtime | Node.js |
| Language | TypeScript (strict) |
| Framework | Next.js (App Router) |
| UI | React (`.tsx`) |
| Packages | npm |

## Getting started

**Requirements:** Node.js 18+ and npm.

```bash
npm install
```

Next.js is not scaffolded in this repo yet. After it is added, use:

```bash
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Project layout

Planned structure once the Next.js app is in place:

```text
app/          Next.js App Router (pages, layouts, API routes)
components/   Reusable React components
lib/          Helpers and server utilities
public/       Static assets
```
